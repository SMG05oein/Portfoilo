## 📖 About The Project

본 레포지토리는 저의 기술적 성장 과정, 실무 외주 프로젝트, 그리고 교내외 수상 경력 등을 체계적으로 기록하고 보여주기 위해 개발된 **개인 포트폴리오 웹 어플리케이션**입니다. 

단순한 이력서를 넘어, 제가 직면했던 기술적 문제들과 이를 해결해 나간 엔지니어링 사고 과정을 마크다운과 코드 블록으로 생생하게 담아냈습니다.

### ✨ Key Features of This Site

- 📱 **Responsive & Glassmorphism UI**: React와 Bootstrap을 활용하여 모바일과 데스크톱 모두에 최적화된 트렌디한 글래스모피즘(투명 유리) 디자인 적용
- 🔍 **Dynamic Filtering & Search**: 프로젝트, 대외활동, 기술 분석 아티클들을 카테고리별로 즉시 필터링하고 검색할 수 있는 동적 UI 구현
- 📝 **Markdown Article Rendering**: `react-markdown`과 `react-syntax-highlighter`를 통해 복잡한 AI 모델 구조나 알고리즘 코드 블록을 보기 좋게 렌더링
- 🤖 **AI-Assisted Development**: 기획부터 컴포넌트 설계, 데이터 정제에 이르기까지 **Agentic AI(Antigravity)** 와 짝 프로그래밍(Pair-Programming) 방식으로 협업하여 생산성 극대화

## 🚀 Getting Started

이 프로젝트를 로컬 환경에서 실행해보고 싶으시다면 아래의 단계를 따라주세요.

### 1. Prerequisites
- Node.js (v18 이상 권장)
- npm 또는 yarn

### 2. Installation & Run
```bash
# 1. 저장소 클론
git clone https://github.com/SMG05oein/Portfoilo.git

# 2. 디렉토리 이동
cd portfolio_react

# 3. 의존성 설치
npm install

# 4. 로컬 개발 서버 실행
npm start
```

> 브라우저에서 (http://smg05oein.github.io/Portfoilo)으로 접속하면 포트폴리오를 확인하실 수 있습니다.
